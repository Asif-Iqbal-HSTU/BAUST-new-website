# Working conventions for this repo

- Do NOT use `EnterWorktree` / git worktrees for tasks in this repo. Edit files directly in the main checkout at `/home/ubuntu/projects/baust-website`, on the current branch (normally `main`), even for background jobs. The user has been burned by worktree-related issues before and wants all edits made directly where the code already lives.
- Commit and push only when explicitly asked.
